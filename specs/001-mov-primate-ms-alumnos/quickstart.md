# Quickstart: Servicio de alumnos

1. Crear usuario y validar rol usuario por defecto.
2. Cambiar rol usuario -> alumno o admin como superadmin.
3. Consultar perfil propio como alumno/admin según el rol asignado.
4. Verificar auditoría del cambio.
5. Desactivar usuario como superadmin y validar bloqueo de acceso.
6. Consultar perfil con contador e historial de reservas.
